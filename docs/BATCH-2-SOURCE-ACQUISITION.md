# Batch 2 — Official Catalog Source Acquisition

## Purpose

Batch 2 must populate the institution → programme → UTME-rule and syllabus taxonomy from authoritative JAMB/IBASS material. No programme combination or syllabus topic is to be guessed.

## Verified official sources

- JAMB official site: https://jamb.gov.ng/
- IBASS Eligibility Checker: https://eligibility.jamb.gov.ng/
- JAMB FAQ: https://jamb.gov.ng/FAQ
- JAMB Departments: https://www.jamb.gov.ng/Departments
- IBASS degree-specific requirements: https://ibass.jamb.gov.ng/assets/uploads/degree-specific-requirements.pdf
- IBASS degree-awarding institution list: https://ibass.jamb.gov.ng/assets/uploads/degree-list-of-schools.pdf
- JAMB/IBASS brochures and manuals are linked from JAMB's official speeches/presentations area.

## Current evidence

JAMB's official Eligibility Checker explicitly uses institution type/category/institution/programme and then provides a UTME subject-combination selection, with English Language selected by default. JAMB's FAQ explicitly directs candidates to IBASS for the programme-specific UTME combination. JAMB's Departments page states that Admissions reviews/updates the UTME brochure and Test Development reviews/develops the UTME syllabus.

## Import rule

These sources are evidence for the acquisition pipeline, not permission to fabricate records. Raw material must be transformed into the catalog import contract, staged, validated, reviewed and approved before publication.

## Current blocker

The live ACE catalog has the full normalized subject foundation and source registry, but zero institution/programme/UTME-rule/topic/subtopic rows. A PDF was not available through the conversation file search, and the IBASS PDF endpoints are not directly extractable through the current browser fetch path. The next required input is authoritative source content that can be downloaded or uploaded so it can be transformed into staged rows.
